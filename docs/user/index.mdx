## What sets it apart

One model family on one class of card, built for the load an agent makes: a
main conversation and its subagents on the same GPU at once.

<div class="ignis-stats not-content">
  <a href="why-ignis/decode-round/"><b>367 tok/s</b>one lane, coding prompts, greedy</a>
  <a href="why-ignis/decode-round/"><b>1,065 tok/s</b>eight lanes at once, aggregate</a>
  <a href="why-ignis/decode-round/"><b>9,717 tok/s</b>cold prefill of a 46K prompt</a>
  <a href="why-ignis/flash-next/"><b>~100 tok/s</b>a 125B MoE on a 32 GB card, one lane</a>
  <a href="why-ignis/kv-in-bytes/"><b>7.11x</b>the KV capacity of BF16</a>
  <a href="why-ignis/decisions/"><b>36.5 ms</b>a decision, zero tokens decoded</a>
  <a href="why-ignis/context-follows-the-card/"><b>896K</b>tokens of context, with vision and DFlash2</a>
  <a href="why-ignis/image-generation/"><b>7.9 s</b>a 2048×2048 image, end to end</a>
</div>
